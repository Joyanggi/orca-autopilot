# 제품 요구사항 문서

상태는 아이디어 결정 대기입니다. 합의한 뒤 상태와 내용을 갱신합니다.

| 항목 | 채울 내용 |
| --- | --- |
| 한 줄 소개 | 누가 언제 무엇을 할 수 있는 앱인가? |
| 해결할 문제 | 사용자가 지금 겪는 불편과 현재 해결 방법은 무엇인가? |
| 주요 사용자 | 첫 버전이 집중할 사용자는 누구인가? |
| 핵심 흐름 | 앱을 처음 열어 원하는 결과를 얻기까지 어떤 순서로 움직이는가? |
| 첫 버전 범위 | 출시 시 꼭 필요한 기능과 이후로 미룰 기능은 무엇인가? |
| 플랫폼과 출시 범위 | 첫 배포 대상과 지원 환경은 무엇인가? |
| 성공 기준 | 앱이 잘 작동하고 사용자가 가치를 얻는지 어떻게 판단할 것인가? |
| 미결정 사항 | 담당자 확인이 필요한 가정, 일정, 제약은 무엇인가? |

상세 인수 기준은 [요구사항](REQUIREMENTS.md)에 기록합니다.
