# 기능 및 비기능 요구사항

첫 버전에 들어갈 동작을 쪼개서 적습니다. 한 항목은 독립적으로 확인할 수 있는 크기로 유지합니다.

| ID | 사용자 상황과 기대 결과 | 우선순위 | 인수 기준 | 검증 방법 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

- 기능 ID는 `F-001`, 비기능 ID는 `NF-001`부터 부여합니다.
- 인수 기준은 시작 조건, 사용자 행동, 관찰할 결과를 포함합니다. 관련된 빈 상태, 오류, 재시도, 저장 후 재실행도 필요에 따라 명시합니다.
- 성능, 접근성, 오프라인, 개인정보 요구는 앱에 실제로 해당하는 항목과 측정 방법을 기록합니다.
