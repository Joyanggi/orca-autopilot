# 마스터에게 보낼 시작 요청문

만들 것이 정해지면 아래 코드 블록을 **{{MASTER_NAME}}** 채팅에 붙여넣습니다. 한두 문장만 적어도 시작할 수 있습니다.

```text
/orchestrate 이 저장소를 첫 프로젝트로 준비해줘. 이번엔 기획·설계까지만 해줘.

만들 것: [한두 문장]
주 사용자와 해결할 문제: [아는 만큼]
첫 버전에 꼭 필요한 기능: [아는 만큼]
제약 또는 참고: [예산, 일정, 유사 서비스, 원하는 플랫폼 등. 없으면 비워둠]

1. README.md, CLAUDE.md, AGENTS.md와 docs/를 먼저 읽고 핵심 사용자, 첫 실행부터 목표 달성까지의 흐름, 첫 버전 범위를 정리해줘. 제품 방향을 바꾸는 미결정 사항만 묻고, 합리적인 초안은 제안으로 표시해줘.
2. docs/product/PRD.md와 REQUIREMENTS.md에 핵심 기능별 인수 기준과 오류 경로를 채워줘. 미정인 부분은 이유와 함께 남겨줘.
3. ARCHITECTURE.md에 기술 스택 조합 하나를 추천해 채우고, 중요한 결정은 docs/decisions/에 근거를 남겨줘. 후보만 나열하지 말고 비용·유지보수·보안 기준으로 하나를 골라줘.
4. docs/quality/의 테스트 전략과 위험 목록을 이 제품에 맞게 채워줘.
5. 초안이 준비되면 첫 버전 범위, 미정 사항, 첫 구현 작업과 확인 기준을 보여줘. 내가 진행하라고 하면 구현을 시작해줘.
```

## 평소 작업 요청

```text
/orchestrate
할 일: [만들 기능이나 고칠 문제]
완료 기준: [사용자가 무엇을 할 수 있어야 하는지]
제약: [있으면. 예: 기획만, 화면은 그대로]
```
