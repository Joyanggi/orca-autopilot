# Orca 앱 화면에서만 바꿀 수 있는 설정

`orca` CLI로 바꿀 수 없어 앱 화면에서 직접(또는 에이전트에게 [자동 적용 프롬프트](ORCA-GUI-AGENT-PROMPT.md)로) 적용하는 설정입니다. 메뉴 이름은 Orca 버전에 따라 조금 다를 수 있습니다. 실제 화면에서 같은 뜻의 항목을 찾으세요.

| # | 설정 | 권장값 | 이유 |
| --- | --- | --- | --- |
| 1 | 새 프로젝트를 여는 위치 | **이 컴퓨터 (Local Mac)** | 원격 서버(예: 집 Windows)가 꺼져 있어도 맥에서 바로 개발 |
| 2 | 사이드바 호스트 필터 | **이 컴퓨터 포함** | 맥 작업공간이 사이드바에 보이도록 |
| 3 | 모바일 에뮬레이터·스킬 확인 호스트 | **Local Mac** | 스킬 상태 확인이 원격으로 향하지 않도록 |
| 4 | 기본 에이전트 | **Claude** | 마스터·개발 작업자가 Claude |
| 5 | Claude·Codex 새 세션 표면 | **Chat** | 폴더 신뢰 질문 없이 채팅으로 시작 |
| 6 | Claude·Codex 새 세션 권한 모드 | **대신 승인 (자동)** | 범위 안의 일상 명령을 승인창 없이 진행 |
| 7 | 워커 승인 위임 | **켜기** | 작업자 권한 요청을 마스터가 이유와 함께 한 번씩 처리 |
| 8 | 사용량 제한 후 자동 재개 | **켜기** | 토큰 한도가 풀리면 멈춘 세션이 이어서 실행 |
| 9 | 에이전트 최대 절전 | **30분 유휴 후** | 메모리 8~16GB 맥에서 백그라운드 에이전트 정리 (실험 기능) |
| 10 | 편집기 자동 저장 | **켜기** | 에이전트와 사람의 편집 충돌 감소 |
| 11 | 워크스페이스 자동 정리 (프로젝트별) | **병합 확인 + 마지막 사용 후 1시간** | 병합된 작업 worktree·로컬 브랜치 정리. 실행 중 에이전트·미커밋 변경·`.env`가 있으면 보류 |
| 12 | 마스터 워크트리 고정(pin) | **`<이름> 마스터` 고정** | 자동 정리 대상에서 제외 |
| 13 | 프로젝트 사이드바 고정 | **프로젝트 폴더 상단 고정** | 빠른 접근 |

## 빠른 명령 (터미널 탭 ▾ 메뉴)

| 이름 | 명령 | 범위 |
| --- | --- | --- |
| `<이름> 마스터 열기` | `orca worktree activate --environment local --worktree 'branch:orca/coordinator'` | 해당 프로젝트 |
| 하네스 점검 | `oap doctor` | 전체 |
| Expo 개발 서버 *(expo)* | `[ -f package.json ] && npx expo start \|\| echo 'Expo 프로젝트 폴더에서 실행하세요'` | 전체 |
| Expo iPhone 개발 빌드 *(expo)* | `[ -f package.json ] && npx expo run:ios --device \|\| echo 'Expo 프로젝트 폴더에서 실행하세요'` | 전체 |
| Expo 프로젝트 진단 *(expo)* | `npx expo-doctor` | 전체 |
| iPhone 연결 확인 *(expo)* | `xcrun devicectl list devices` | 전체 |

## 앱 밖에서 한 번 확인할 것

- Codex 계정 로그인: Orca의 계정 관리에서 Codex 계정이 로그인 상태인지 확인합니다. 갱신 오류가 나면 Codex 리뷰가 시작되지 않습니다.
- (모바일) Xcode의 외부 에이전트 접근은 `Never`로 두고, 기기 조작은 Mobile MCP로만 합니다.
