# Orca 설정 자동 적용 프롬프트

Orca에서 Claude Code 또는 Codex 채팅을 열고 아래 블록을 붙여넣습니다. 에이전트가 Orca 컴퓨터 사용 스킬로 앱 화면을 직접 조작합니다. `<…>` 부분을 채우세요.

```text
$orca-computer-use 스킬과 $orca-cli 스킬을 사용해서, 이 맥의 Orca 앱 설정을 아래 목록대로 맞춰줘.
목록: orca-autopilot의 docs/ORCA-GUI-SETTINGS.md (경로: <키트 경로>/docs/ORCA-GUI-SETTINGS.md)
프로젝트 이름: <이름>, 프로젝트 경로: <저장소 경로>, 프리셋: <expo 또는 generic>

규칙
1. 먼저 각 설정의 현재 값을 읽고, 이미 권장값이면 건드리지 마.
2. CLI로 할 수 있는 건 CLI로 하고(orca repo/worktree/skills 등), 화면에서만 바뀌는 항목만 화면을 조작해.
3. 메뉴 이름이 목록과 다르면 같은 뜻의 항목을 찾고, 찾지 못하면 바꾸지 말고 "못 찾음"으로 보고해.
4. 계정 로그인, 결제, 비밀번호 입력, 다른 원격 서버 삭제는 하지 마. 필요하면 나에게 물어봐.
5. 빠른 명령은 목록의 '빠른 명령' 표에서 프리셋에 맞는 것만 추가하고, 같은 이름이 있으면 덮어쓰지 마.
6. 끝나면 항목별로 (이전 값 → 바꾼 값 / 그대로 / 못 찾음) 표로 보고하고, 새 채팅을 하나 열어 권한 모드가 '대신 승인'으로 시작하는지 확인해.
```
