# 앱 아키텍처

개발 방향은 **Expo, React Native, TypeScript**이고 첫 실기기 검증은 **iPhone**입니다. Expo SDK 버전, 패키지 관리자, 프로젝트 생성 명령은 실제 초기화 시점에 공식 문서와 로컬 환경(Node.js 22.13 이상)으로 확인합니다.

| 항목 | 채울 내용 |
| --- | --- |
| 앱 구성 | 주요 화면, 내비게이션, 기능 단위 폴더 구조 |
| 데이터 | 저장할 정보, 저장 위치, 상태 동기화 및 삭제 |
| 서버와 연동 | 서버가 필요한지, 필요한 경우 API와 인증 경계 |
| 권한과 개인정보 | 요청할 기기 권한, 이유, 거부 시 동작, 데이터 처리 방식 |
| 플랫폼 | 앱 표시 이름, iOS bundle identifier, Android package name, 지원 대상 |
| 빌드 설정 | 개발 빌드(`expo-dev-client`) 절차, 환경변수 이름과 주입 방법 |
| 배포 | 첫 배포 대상, EAS 등 빌드와 제출 방식, 장애 시 복구 방법 |

앱 식별자(bundle identifier, package name)와 URL 스킴은 출시 후 바꾸기 어려우므로 마스터가 자동으로 정하지 않고 사람에게 묻습니다. 선택 이유와 변경 비용이 중요한 항목은 [ADR](../decisions/README.md)로 남깁니다.
