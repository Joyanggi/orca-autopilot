# 테스트 전략

프로젝트 초기화 후 실제 실행해 본 명령을 등록합니다. 검증 기록에는 명령, 결과, 사용한 환경, 실행하지 못한 이유를 남깁니다.

| 검사 | 대상 | 실제 명령 또는 절차 |
| --- | --- | --- |
| 타입 검사와 린트 | 프로젝트 기본 검사 | 초기화 후 기입 |
| 단위 및 통합 테스트 | 핵심 로직과 데이터 처리 | 해당 요구사항이 생기면 기입 |
| 빌드 및 실행 | 설치, 첫 실행, 기본 흐름 진입 | 초기화 후 기입 |
| 수동 확인 | 자동화하기 어려운 핵심 흐름 | 필요해지면 기입 |

CI(`{{CI_NAME}}`)에는 로컬에서 확인 가능한 검사부터 연결합니다. `package.json`에 `lint`, `typecheck`, `test` 스크립트를 정의하면 CI가 자동으로 실행합니다. 핵심 검사가 추가되면 안전한 실패 입력으로 검사 자체가 실패를 포착하는지 확인합니다.
